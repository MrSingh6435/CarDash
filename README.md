## 💡 Overview

**CarDash** is my **first mobile game**, an endless runner–style car game focused on smooth controls, responsive UI interactions, and performance-friendly systems.  
Built using **Unity** and **C#**, this project helped me understand mobile game flow, object pooling, and player experience design.

The goal is simple — **survive as long as possible**, avoid traffic, and keep moving forward.

---

## 🧠 Core Concepts & Systems

- 🚘 **Swipe-based lane movement** for mobile-friendly controls  
- 🛣 **Endless road system** using path repositioning  
- 🚦 **Traffic car system** with randomized spawning  
- ♻️ **Object pooling** for performance optimization  
- ⏸ **Game flow UI**
  - Start Game panel  
  - Pause panel with **3-2-1 resume countdown**  
  - Game Over panel with delayed appearance  
- 🌐 **Custom Curved World Shader** for depth and speed feel  
- 🎥 **Camera-based distance handling** for cleanup and reuse

## 🎮 Gameplay Summary

🚗 The player controls a car that automatically moves forward.  
Using **left and right swipe gestures**, the player switches lanes to avoid incoming traffic.

🎯 **Goal:**  
Survive as long as possible without crashing.

💥 **Challenge:**  
Increasing traffic, quick reactions, and precise lane switching.
